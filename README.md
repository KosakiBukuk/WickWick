CapWick

1인칭 스텔스 액션 게임 (Unity / C#, 1인 개발)

CapWick은 은신과 암살을 중심으로 한 1인칭 암살 액션 게임입니다. 플레이어는 적의 시야를 피해 은밀하게 탈출구까지 진입해야합니다.
적은 플레이어의 걷는 소리와 뛰는 소리를 감지할수있으며, 적을 더 많이 들키지 않고 빠르게 제압할수록 더 큰 점수를 얻게 됩니다.

조작법
WASD 기본 움직임
C 앉기(은신)
SHIFT 달리기
SPACE 점프
ESC 일시정지
